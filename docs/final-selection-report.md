# 📊 가용 자원 기반 최적의 LLM 최종 선정 보고서

## 1. 체급별 인프라 한계 테스트 결과 요약

### ❌ A. Qwen/Qwen3.5-27B (대형 체급) - 불합격
- **자원 분석:** 4bit 효율화 적재를 적용하더라도 초기 모델 로딩 무게만 약 12.94 GB를 소모함.
- **판단:** 이미 하드웨어 물리 한계선(8GB) 및 가용 안전선(6.4GB)을 한참 초과하여 초기 구동 단계에서 시스템 다운(OOM) 발생. 학습 및 서비스 불가능.

### 🔺 B. Qwen/Qwen3-0.6B (초경량 체급) - 보류 (효율 저하)
- **자원 분석:** 기저 모델 가중치는 0.33 GB로 극도로 가벼우나, 남는 메모리를 채우기 위해 문맥을 2048까지 늘려도 전체 자원의 20% 대(2.15 GB) 밖에 쓰지 못함.
- **판단:** 하드웨어 가용 자원을 과도하게 낭비하며, 파라미터 크기가 너무 작아 복잡한 사내 약관 해석이나 정밀 요약 지능이 다소 부족함.

### 👑 C. Qwen/Qwen3.5-4B (가성비 실무 체급) - 🎉 최종 채택 (적격)
- **자원 분석:** 16비트 강제 유지층(임베딩 레이어)과 압축 구역을 정밀 분리하여 초기 로드 무게를 약 2.06 GB로 안정화함.
- **최적 훈련 스펙 유도:** 물리 배치 사이즈 `2` / 최대 문맥 길이 `1024 토큰` 조합 자동 도출.
- **연산 피크 VRAM 예측:** 연산 시 실시간 데이터 복원 버퍼 및 메모리 가속 기술을 적용했을 때 최대 피크 용량 **약 6.11 GB** 기록.

## 2. 최종 결론
- `Qwen3.5-4B` 모델은 RTX 5060 8GB의 안전 마지노선(6.40 GB)을 완벽하게 준수하면서, 사내 문서를 한 번에 1,024 토큰씩 대량으로 학습/추론할 수 있는 가장 완벽한 황금 밸런스 모델로 검증되어 최종 도입을 확정함.
