# 📑 오픈소스 거대 언어 모델(LLM) 후보 2종 정밀 비교 분석서

본 문서는 사내 문서 자동 요약 파이프라인 구축을 위해 선정된 후보 오픈소스 제품군의 하드웨어 스펙 및 기술 태그를 비교 검증한 자료입니다.

| 비교 지표 항목 | 👑 후보 1: Google Gemma-4-E4B-it | 👑 후보 2: Alibaba Qwen/Qwen3.5-4B |
| :--- | :--- | :--- |

## 2. 인프라 관점에서의 비교 분석 요약

### 💡 구글 Gemma-4-E4B-it 모델의 특성
- **강점:** 단어 사전 크기가 26만 개로 압축률이 높아 한국어 문장을 구사할 때 번역투 없이 극도로 자연스럽고 유려한 보고서 문체 요약본을 생성함.
- **자원 측면:** 단어 사전 임베딩 층의 용량 비중이 다소 커서 초기 정적 로딩 무게가 살짝 묵직하게 잡히는 특성이 있음.

### 💡 알리바바 Qwen3.5-4B 모델의 특성
- **강점:** 두뇌 회로(레이어 수)와 단어 사전 크기가 매우 슬림하게 다이어트되어 있어, 물리적으로 8GB 그래픽카드 자원을 가장 쾌적하게 쥐어짜 내기에 유리함.
- **자원 측면:** 가벼운 체급 덕분에 메모리 공간 유동 풀이 넓어져, 훈련 시 안전하게 물리 배치를 `2` 이상으로 키우고 `1024 토큰` 수준의 긴 문서 문단을 OOM 에러 없이 받아내기에 최적화되어 있음.
